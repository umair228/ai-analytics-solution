## Approach

The traceability matrix is executable code (`validation/requirements.py`), not a table in a document. Each requirement names the automated tests that verify it, by import path; `manage.py qualify` runs them and **fails if a named test does not exist**. A matrix that cannot rot is the only kind worth having.

This follows GAMP 5 (2nd ed.) and the CSA position that automated tests are legitimate — and better — qualification evidence than a screenshot of someone clicking: they are repeatable, dated, and they run again on every change.

### Why each requirement exists

**URS-001 — The system shall never modify data in the source LIMS.**  
DIS is a decision-support layer; the LIMS remains the system of record. A write from an analytics tool is an uncontrolled change to a GxP record.

**URS-002 — The system shall not report a censored or non-numeric result (e.g. '<0.05', 'ND') as a number.**  
A censored result read as zero drags an average down and can turn an off-spec batch into a passing one. SQLite's CAST('<0.05' AS REAL) returns 0.0, not NULL — this failure was real, and shipped.

**URS-003 — A figure shall have the same value regardless of which supported data source it is computed from.**  
A laboratory that moves from the LIMS to a replica must not see its numbers change. DATEDIFF(hour, …) truncates to whole hours on MSSQL while Postgres returns the fraction — the same turnaround tile answered differently per dialect.

**URS-004 — The system shall not certify a sample as conforming unless every test ordered against it has been reported and adjudicated.**  
A test ordered and never reported is the dangerous case: a certificate that lists only the results it happens to find, sees no failures, and prints CONFORMS is a batch released without being fully tested.

**URS-005 — Numerical figures shall be produced by deterministic, unit-tested engines and never by the language model.**  
A language model that computes can be confidently wrong. The model selects and narrates; the validated engine computes.

**URS-010 — The audit trail shall be append-only.**  
An audit trail a user can delete is not an audit trail. This system previously denied add and change in the admin but not delete.
  
> ⚠️ Enforced at the APPLICATION layer. A holder of direct database credentials can still alter the table — see URS-062.

**URS-011 — An action that cannot be recorded in the audit trail shall not occur.**  
A silently-failing audit write is worse than none: the gap is indistinguishable from 'nothing happened'.

**URS-012 — SQL generated by the language model shall be recorded, with its content, attributable to the user who caused it.**  
An LLM composing SQL against the LIMS is the highest-risk action in the product. It previously produced no log entry at all.

**URS-013 — Records shall survive the deletion of the user account that created them.**  
Offboarding an employee must not erase the record of what the system told them. Conversation.owner previously CASCADEd.

**URS-020 — Applying a signature shall require re-authentication of the signer (§11.200).**  
Being logged in is not signing. An unattended terminal must not be able to release a batch.

**URS-021 — A signature shall be invalidated if the record it signed is subsequently altered (§11.70).**  
A signature that merely points at a row can be transferred to a record that says something else. It must bind to the content.

**URS-022 — A signature shall record the printed name of the signer, the date and time, and the MEANING of the signature (§11.50).**  
A signature with no meaning records that somebody clicked something.

**URS-023 — A certificate that cannot account for every test ordered shall not be approvable.**  
Authority does not substitute for a missing result. Refusal must be at the door, not a warning that can be clicked past.

**URS-030 — Laboratory data shall not be transmitted outside the customer network without an explicit, deliberate configuration act.**  
Prompts carry sample rows. The provider defaulted to the cloud, so a missing .env file would have exfiltrated LIMS records.

**URS-031 — A user shall not be able to read data belonging to another user's private knowledge base.**  
Cross-tenant retrieval leakage in a RAG index is silent and total.

**URS-040 — The same question shall produce the same answer.**  
'We re-ran it and got a different number' ends a CSV conversation. The Anthropic path previously passed no temperature at all and ran at the API default of 1.0.
  
> ⚠️ temperature=0 + a fixed seed is the closest a hosted LLM gets to determinism. The deterministic ENGINES are exactly reproducible (fixed random_state); the narrative prose is not guaranteed to be byte-identical. Figures are reproducible; wording may vary.

**URS-041 — Statistical process-control rules shall be implemented correctly, and shall distinguish a warning from a rejection.**  
Westgard 1₂ₛ is a warning. An alert that rejects on it would page someone one run in twenty, forever — which is how a QC scheme gets switched off.

**URS-042 — A predictive model shall not use information that is unavailable at the moment of prediction, and shall declare itself unusable when it cannot predict.**  
A model trained on the result value scores 0.99 and cannot run on a live sample. A ranked list of at-risk samples from a useless model looks exactly like one from a good model.

**URS-043 — Generated SQL shall be validated before execution and the system shall refuse rather than guess.**  
A confidently wrong number is the principal risk of this product.

**URS-044 — A certified metric shall NEVER answer a question it cannot honour. Router precision shall be 1.0 on the routing benchmark.**  
The certified path bypasses the LLM AND the validator, so a wrong match is a confidently-wrong deterministic answer carrying a 'Certified' badge. Asking 'how many results are off-spec LAST MONTH' and being handed the all-time total, stamped certified, is the worst failure this system can produce. A MISS is cheap — it falls through to the validated long-tail. The two are not symmetric, and precision is therefore not negotiable.
  
> ⚠️ This is the only accuracy claim in the product that can be gated in CI: the router is a pure function of the question and the curated layer, so it needs no LLM and no database. 64 benchmark cases, 26 of them adversarial questions the router must REFUSE.

**URS-050 — Every answer shall state how current the data behind it is.**  
An answer computed from a three-day-stale replica must not be indistinguishable from a live one. `freshness` was previously a hardcoded string literal.

**URS-051 — A replica that has stopped refreshing shall be detected and reported, not served silently.**  
A silently-failing replication serves stale data with full confidence, indefinitely, and nobody finds out.

**URS-052 — A user shall be able to see, on demand, the exact query that produced any figure.**  
A number you cannot trace is a number you cannot defend.
