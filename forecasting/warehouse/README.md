# Oil & Gas LIMS Forecasting Warehouse

`refinery_lims.sqlite3` is a **self-contained, deterministic oil-&-gas refinery
LIMS warehouse** that powers the three LIMS Forecasting features. It is committed
here (not under `media/`, so it is never shadowed by the Docker media volume) and
ships inside the API image — forecasting works out of the box, locally and on the
server, with no external SQL Server.

Point forecasting at it with a single env var (`FORECAST_DB_ENGINE=sqlite`); the
path defaults to this file. Regenerate deterministically (same RNG seed → identical
data → the committed models stay valid) with:

```
python manage.py seed_forecast_warehouse --force        # rebuild the DB
python manage.py seed_forecast_warehouse --force --prewarm   # + retrain models
```

## The laboratory-intelligence story

A mid-size refinery runs a central QC laboratory across seven analytical sections
(Crude & Distillation, Gasoline/Mogas, Naphtha & Aromatics, Middle Distillates,
Fuel Oil & Asphalt, Gas & LPG, Environmental & Water). Every crude receipt,
blend, and product batch is sampled, logged, tested against ASTM/ISO specs, and
released. The lab is instrument- and reagent-intensive: GCs, distillation units,
density meters, XRF sulphur analysers, Karl-Fischer titrators — all of which drift,
fail, and need calibration — and it consumes carrier gases, standards, and solvents
that must be reordered before they run out. Three questions decide whether the lab
keeps the plant running:

1. **How much work is coming?** (sample volume) — staffing & shift planning.
2. **Which instruments will cost us uptime?** (downtime) — maintenance & spares.
3. **When do we reorder critical consumables?** (inventory) — stock-outs stop tests.

The warehouse encodes ~5.5 years of history (Jan 2021 → mid-2026) with realistic
**seasonality** (turnaround campaigns, summer gasoline/winter distillate swings),
**trends** (throughput creep, ageing instruments), and **noise**, so NeuralProphet
learns genuine patterns rather than a straight line.

## What each forecast reads (mirrors real LabWare column names)

| Forecast | Table(s) | Key columns | Technique |
|---|---|---|---|
| **Sample volume** (all labs + per section) | `SAMPLE` | `LOGIN_DATE`, `GROUP_NAME` → section | monthly sample counts → NeuralProphet (yearly seasonality, multiplicative) |
| **Instrument downtime** | `INSTRUMENTS1_LOG` | `INSTRUMENT`, `EVENT_TYPE` (`ON`/`OFF`), `ENTERED_ON` | OFF→next-event durations summed per month → NeuralProphet |
| **Inventory consumption** | `INVENTORY_TRANS` ⋈ `INVENTORY_ITEM` | `STOCK`, `TRANSACTION_TYPE='PULL'`, `TRANSACTION_STATUS='C'`, `QUANTITY`, `TRANSACTION_DATE` | monthly `PULL` quantity → NeuralProphet |

Demo entry points with trained models:
- Downtime instruments: **GC-401** (default), ADU-05, VACDIST-01, KF-04, XRF-S-03, …
- Sample sections: all seven (e.g. **Middle Distillates**, **Gasoline/Mogas**).
- Inventory stocks: **METHANOL**, **ETHANOL**.

Generated by `seed_refinery/build_warehouse.py` from `seed_refinery/reference.json`
(researched refinery reference data: sections, ~39 products, ASTM tests, instruments,
reagents). ~22.3k samples, ~9.8k instrument events, ~3k inventory transactions.
